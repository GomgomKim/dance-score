# dance-score 💃 AI 안무 채점기

원본 안무 영상과 내 춤을 **포즈 인식으로 비교해서 8카운트마다 점수**를 매기는 웹앱.
인스타 릴스 "AI한테 내 춤 채점 맡겨봄" 시리즈용으로 만들었습니다.

- **분석 모드**: 원본 영상 + 내 춤 영상 업로드 → 진행률 표시 → 결과 화면
- **라이브 모드**: 원본 재생 + 옆에 웹캠, 8카운트마다 PERFECT / GREAT / GOOD / MISS 팝업이 실시간으로 뜸
- **데모 모드**: 가짜 분석 데이터로 결과 화면을 바로 확인 (`/?demo` 또는 "데모 결과 보기" 버튼)

영상은 **서버로 전송되지 않습니다.** 포즈 인식(MediaPipe)이 전부 브라우저 안에서 돌아가요.
(처음 한 번 포즈 인식 모델 파일만 구글 스토리지에서 내려받습니다.)

## 로컬 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 유닛 테스트 (vitest)
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 확인
```

- Node 20 이상 권장
- 웹캠(라이브 모드)은 `localhost` 또는 HTTPS에서만 동작합니다. 폰으로 테스트하려면 Vercel에 배포하는 게 제일 편해요.
- 크롬 / 엣지 / 사파리 최신 버전 기준. 비교 영상 녹화는 브라우저에 따라 mp4 또는 webm으로 저장됩니다.

## 사용 순서

1. **원본 안무 영상** 업로드. 거울 모드(좌우 반전) 영상이면 "좌우 반전"을 켜세요.
2. **박자 맞추기**
   - BPM을 직접 입력하거나, 노래에 맞춰 **TAP** 버튼(또는 `T` 키)을 4번 이상 누르거나, **🎵 자동 추정**
   - 원본을 재생하다가 안무의 "1"이 나오는 순간 **📍 지금 위치를 1로**. 미리보기 위에 카운트가 떠서 맞는지 바로 확인할 수 있어요. (메트로놈 소리도 켤 수 있음)
3. **분석 모드**: 내 춤 영상을 업로드하고 **🔊 오디오로 자동 싱크**(같은 노래를 틀고 찍었다면 제일 정확) → 분석 시작
   **라이브 모드**: 시작 → 3초 카운트다운 → 춤!
4. **결과 화면**
   - 총점 카운트업 + 등급별 이펙트/효과음 (🔁 버튼으로 몇 번이든 다시 연출 → 촬영 재도전용)
   - 8카운트별 점수 막대 그래프 (막대를 누르면 그 구간 다시 보기)
   - 제일 못한 구간을 원본과 내 영상 나란히 + 스켈레톤 오버레이로 다시 재생. 내 영상 위에 원본 동작이 반투명 "고스트"로 겹쳐지고, 틀린 부위는 노란색으로 강조
   - 🎬 나란히 비교 영상 녹화 & 다운로드 (세로 9:16 릴스용 / 가로 16:9, 구간만 / 전체)
   - 📸 9:16 결과 카드 이미지 저장 (곡 제목, 닉네임, 날짜, 총점, 등급, 그래프)

## 채점 방식 (릴스 댓글 질문 대비용)

> **Q. 이거 진짜 AI가 채점하는 거예요?**
> 네. 구글의 포즈 인식 AI(MediaPipe)가 영상 프레임마다 몸의 관절 33개 위치를 찾고, 원본과 내 관절 각도를 비교해서 점수를 냅니다. 사람이 손으로 점수를 넣는 건 없어요.

1. **포즈 추출**: 두 영상에서 초당 15프레임(설정 가능)씩 관절 33개의 위치를 뽑습니다.
2. **정규화**: 골반 중심을 원점으로 옮기고 몸통 길이(골반~어깨)를 1로 맞춥니다.
   → **키, 체형, 카메라와의 거리, 화면 속 위치가 달라도** 같은 자세면 같은 값이 돼요.
3. **프레임 유사도**: 위팔·아래팔·허벅지·정강이·몸통·고개 방향 벡터 12개를 원본과 비교합니다.
   - 벡터마다 **코사인 유사도의 제곱** (0° → 1, 30° → 0.75, 45° → 0.5, 90° 이상 → 0)
   - 부위별 가중 평균: 팔 1.0, 다리 0.9, 몸통 0.7, 머리 0.3 (춤은 팔 동작 비중이 커서)
   - 원본에서 가려진 관절은 채점에서 빠집니다
4. **타이밍 보정 (DTW)**: 살짝 빠르거나 늦은 건 Dynamic Time Warping으로 프레임을 맞춰서 **동작 자체는 공정하게** 비교합니다.
   대신 **얼마나 밀렸는지는 따로 타이밍 점수로** 반영해요. (1/8박 이내면 만점, 1박 밀리면 0점)
5. **8카운트 구간 점수**: BPM과 첫 카운트 위치로 8박씩 나눠서, 구간마다
   `점수 = 포즈 점수 × 70% + 타이밍 점수 × 30%` (0~100)
6. **등급**: PERFECT 90+ / GREAT 75+ / GOOD 55+ / MISS
7. **가장 많이 틀린 부위**: 구간마다 부위별 점수가 제일 낮은 곳을 찾고,
   - 그 부위만 앞뒤로 밀어보며 가장 잘 맞는 지연을 찾아 → "왼팔이 **반 박자 늦어요**"
   - 타이밍 문제가 아니면 관절 굽힘/높이를 비교해서 → "오른팔을 **더 쭉 펴주세요**", "**더 높이 올려주세요**"
   - 몸 전체가 밀렸으면 → "**전체적으로** 반 박자 늦어요"

총점은 구간 점수의 평균(박 수 가중)입니다.

> **Q. 저 분명 잘 췄는데 점수가 낮아요**
> 대부분 ① 전신이 안 나왔거나 ② 원본과 카메라 각도가 다르거나 ③ 첫 카운트 위치(싱크)가 어긋난 경우예요. 아래 촬영 팁을 참고하세요.

> **Q. 거울 모드 영상으로 연습했는데요?**
> "좌우 반전"을 켜면 원본을 뒤집어서 왼쪽/오른쪽까지 맞춰서 비교합니다.

## 촬영 잘 나오는 팁 📸

- **전신이 다 나오게**: 머리부터 발끝까지. 발이 잘리면 다리 점수가 엉망이 돼요. 폰을 2~3m 떨어뜨려 세로로 세우세요.
- **밝은 조명**: 역광(창문 등지기) 피하기. 얼굴 쪽에서 빛이 오게.
- **원본이랑 비슷한 각도**: 원본이 정면이면 나도 정면, 원본이 살짝 위에서 찍었으면 비슷하게. 각도가 다르면 팔다리 방향이 달라 보여서 감점돼요.
- **몸에 붙는 옷 + 배경과 다른 색**: 펑퍼짐한 옷은 관절 위치가 흔들려요.
- **한 명만 화면에**: 뒤에 사람이 지나가면 엉뚱한 사람을 잡을 수 있어요.
- **같은 노래를 틀고 찍기**: 분석 모드에서 "오디오로 자동 싱크"가 정확하게 맞춰줍니다.
- **라이브 모드는 스피커로**: 이어폰 끼면 원본 소리가 녹화본에 안 들어가요.

## 코드 구조

```
src/
  pose/                ← 포즈 관련 순수 로직 (다른 프로젝트에서 재사용 가능)
    types.ts           타입 (Pose, PoseSequence, SegmentResult, AnalysisResult …)
    landmarks.ts       MediaPipe 랜드마크 인덱스, 좌우 반전, 스켈레톤 연결선
    normalize.ts       정규화 (골반 원점 + 몸통 길이 스케일)
    similarity.ts      관절 벡터 추출, 코사인 각도 유사도, 부위별 가중 평균
    dtw.ts             DTW (Sakoe-Chiba band, 열린 시작/끝)
    segments.ts        BPM → 8카운트 구간 분할, 현재 카운트 계산
    grading.ts         등급 판정, 점수 변환
    feedback.ts        부위별 지연 추정, "왼팔이 반 박자 늦어요" 코멘트 생성
    scoring.ts         전체 파이프라인 analyzeSequences(ref, user, {bpm, offset})
    sequence.ts        리샘플링, 시간 정렬
    synthetic.ts       가짜 랜드마크 생성기 (테스트/데모용)
    index.ts           ↑ 순수 로직만 export
    landmarker.ts      MediaPipe PoseLandmarker 래퍼 (브라우저 전용)
    extract.ts         영상 → 포즈 시퀀스 (seek 방식, 브라우저 전용)
    draw.ts            캔버스 스켈레톤 그리기 (브라우저 전용)
  audio/
    tempo.ts           탭 템포, BPM 자동 추정, 오디오 싱크 (순수 함수)
    decode.ts          파일 → 오디오 샘플
    sfx.ts             Web Audio 합성 효과음 (음원 파일 없음)
  components/          화면들 (Setup / Analyzing / Live / Result …)
  config/brand.ts      브랜드 설정 (워터마크 문구, 핸들, 주소, 로고)
  lib/                 결과 카드 렌더링, 워터마크, MediaRecorder, 다운로드
  demo/                데모 모드 세션
```

`src/pose`의 순수 로직은 DOM이나 MediaPipe에 의존하지 않아서 그대로 복사해 다른 프로젝트에서 쓸 수 있어요:

```ts
import { analyzeSequences } from './pose';
const result = analyzeSequences(refSequence, userSequence, { bpm: 120, offset: 0.5 });
```

## 테스트

웹캠은 자동 테스트가 안 되니까, 채점 로직은 전부 순수 함수로 분리해서 가짜 랜드마크로 테스트합니다 (`npm test`).

- 정규화: 체형/거리/위치/화면 비율이 달라도 같은 자세면 같은 좌표
- 각도 유사도: 같은 포즈 1, 각도 오차가 클수록 감소, 가려진 관절 제외
- DTW: 밀린 시퀀스를 밀린 만큼 매칭, band 제한, 경로 연속성
- BPM 구간 분할 / 현재 카운트, 등급 경계값
- 통합: **같은 시퀀스끼리 100점 근처**, **시간을 밀면 타이밍 점수와 총점 하락**, **팔 각도를 틀면 그 구간 점수 하락 + 왼팔 지적**, 왼팔만 반 박자 늦으면 "왼팔이 반 박자 늦어요", 거울 모드 반전
- 탭 템포, 클릭 트랙 BPM 추정, 오디오 싱크 오프셋
